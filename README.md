# Essência Body Care — versão moderna

Projeto estático pensado para hospedagem no GitHub Pages.

## Recursos
- Home com hero e categorias.
- Catálogo com busca e ordenação.
- Filtros por categoria.
- Página de detalhes de produto com `Produto.html?id=...`.
- Carrinho lateral com `localStorage`.
- Controle de quantidade.
- Checkout demonstrativo.
- Layout responsivo.
- Imagens em `contain` para evitar cortes.
